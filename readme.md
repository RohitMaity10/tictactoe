# 🎮 Tic-Tac-Toe Game

A clean, responsive Tic-Tac-Toe web game built with Vanilla JavaScript, HTML5, and CSS3.

## Features
- Turn indicator showing Player X and Player O
- Live score tracker (Player X, Ties, Player O)
- Win combination animations
- Playable on both desktop and mobile devices
